# Master Ten プライバシー

最終更新: 2026-08-06

Master Tenは、個人でオフライン利用できる静的Webアプリです。

## 収集・送信しないもの

- 氏名、メールアドレス、位置情報その他の個人情報
- プレイ履歴、盤面、クリア記録、設定
- 端末識別子、広告識別子、Cookieによる追跡情報
- 分析イベント、クラッシュログ、ランキング情報

広告SDK、分析SDK、認証SDK、通知、ログイン、アプリ内課金、外部ゲームAPI、独自バックエンドはありません。ゲーム中に第三者CDNや外部フォントへ接続しません。

## 端末内に保存するもの

localStorageへ次を保存します。

- 進行中の問題、盤面、履歴、手数、時間、各アシスト回数
- クリア済み問題とノーアシスト記録
- 文字サイズ、音、振動、動き、高コントラスト、盤面サイズの設定

これらは利用中のブラウザ・端末内だけに残り、GitHubや開発者へ送信されません。設定画面の「セーブデータを削除」でMaster Ten所有データを削除できます。

## ネットワーク利用

初回表示と更新時にGitHub Pagesから同一オリジンのHTML、CSS、JavaScript、manifest、Service Worker、アイコンを取得します。Service Workerはそれらをオフライン用に保存します。ゲームの問題データはJavaScript配布物に含まれ、プレイ中の外部通信を必要としません。

GitHub Pages自体の運用についてはGitHubの利用条件・プライバシー方針が適用されます。Master Tenは追加の計測や送信を実装していません。
