- より少ない追加上限を全探索し、最小追加回数を全問で証明。
- 初期合法手は全問10以上。

- 初期行は8、9、10、11、12で相違。

- 問題ID、seed、初期盤面ハッシュ、占有構造署名は全て一意。

## 3. 構造差の目視確認

- 問題1: 疎な行シェルの後に、複数の7が競合する2行の罠核。
- 問題2: 反転した罠核を重ねた4行核で、初期候補数が最多。
- 問題3: 10行から縮退した後、8数字の成長局面へ入る。
- 問題4: 11行、短い4数字核、初期誘惑手10、探索展開が問題3より大きい。
- 問題5: 12行、最短の2数字核から成長し、5問中最大の探索展開と誘惑手数。

単なる数字置換なら占有構造署名が同じになる。5問は署名が全て異なり、行数、空所位置、核長、解長、分岐特性にも差がある。

## 4. 現時点の制限

- `provenOptimal` は任意解DFSでは原則false。最小追加回数は証明済みだが、同じ追加回数内の最短総手数は未証明。
- `estimatedSolutionCount` は完全な全解数ではなく、初期安全手数の代理値。
- Master判定は設計特徴量に基づく。実プレイによる楽しさ・理不尽さのレビューは30問化後も継続する。

## 5. 30問公開ゲート

最初の5問の構造とメタデータを維持したまま、同じ生成・検証パイプラインを30問へ拡張した。初回の30問生成では占有構造の重複を検出して書出しを拒否した。6問目以降へ数字置換では消えない空所間隔の構造マーカーを追加し、再生成後に全30署名の一意性を確認した。

- 収録数: 30問。
- 設計族: 5種を各6問。
- 初期行: 8、9、10、11、12行を各6問。
- 可解性: 全30問 `SOLVED`、`UNKNOWN` 0問。
- 初期合法手: 全問1手以上。
- 最小追加: 0回が12問、1回が17問、2回が1問。全問証明済み。
- 追加必須: 18問。
- 保存解長: 10～20手。
- 難易度: 65～90。
- 構造重複: 問題ID、seed、初期盤面ハッシュ、占有構造署名の重複0。
- 解再生: 全30問で最終 `WON`。
- 安全ヒント: 保存解の全局面で検証済み手を返し、無保証手の提示0。
- 最大高さ: 全問48行以内、実測では初期8～12行の範囲以内。
- 追加上限: 全問3回以内。

構造署名は空所と生存セルの配置を対象とするため、単純な数字置換だけの問題は同じ署名となり重複採用できない。5設計族、5段階の初期行、6種の空所間隔群を組み合わせ、目視上も盤面核、行数、空所位置が異なる。
