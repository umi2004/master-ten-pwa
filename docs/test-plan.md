# Master Ten テスト計画

## 1. 品質ゲート

各フェーズのpush前に `npm test` と `npm run build` を成功させる。コミット後はローカルSHAと `origin/main` を照合する。失敗テストの無効化や削除だけで通過させない。

## 2. ルールエンジン単体テスト

- 同じ数字の隣接ペア、合計10、5と5、数値不一致
- 空所越し水平・垂直・左右斜め
- 生存数字による遮断、各方向で最初の生存数字のみ
- 行末と次行頭、複数空所を含む読み順接続、同一行では読み順規則を使わない
- 生存数字を挟む行またぎ無効、直線・読み順重複排除
- 完全空行と空の部分最終行の削除、行削除後の位置更新
- 生存数字の読み順追加、削除セル非複製、部分最終行への連続追加、過去穴を埋めない
- 有効手ありで追加拒否、有効手0で追加可能、残数減少、上限超過拒否
- 勝利・敗北・継続判定
- 不正位置・不正手の拒否
- 入力配列・状態・履歴を破壊しないこと
- 同一入力・同一操作が同一結果になること

## 3. ソルバー単体テスト

- 既知の単純可解、既知の不可能、追加なし可解
- 追加1回必須、追加残数不足で不可能
- 合流する重複状態の展開抑制
- 同じ問題を複数回解いた結果と解順が一致
- ノード、時間、深度上限で `UNKNOWN`
- 全探索完了時だけ `UNSOLVABLE`
- 小盤面でBFSと実用DFSの可解性一致
- 解答手順再適用で勝利
- 状態キーが盤面、論理長、追加残数、ルール版を区別
- 統計、終了理由、最適性・最小追加証明フラグの整合

## 4. ヒント単体テスト

- 完走経路上の安全なペアを返す
- 詰みへ進む合法手を返さない
- 複数解でも少なくとも一つの安全手を返す
- 安全な数字追加を返す
- `UNKNOWN` 時は手を返さず説明を返す
- 状態変更後に古いキャッシュを使わない
- 解経路外の手後に再探索する
- ヒント回数を記録する

## 5. 問題生成・データ検証

5問の初期ゲートと30問の公開ゲートで、以下を自動検査する。

- 問題ID一意、seed一意または共有理由あり、全版一致
- 初期盤面ハッシュ、行数、論理長、セル範囲、追加上限
- 初期合法手1つ以上、`SOLVED`、`UNKNOWN` なし
- 保存解の再生で勝利、最大48行、追加3回以内
- 5問では構造差、追加必須2問以上、必要追加回数の差、誘惑手の存在
- 30問では全メタデータ整合、安全ヒントを解経路全局面で生成可能
- 完全盤面重複、正規化盤面重複、単純数字置換だけの構造重複を検出
- 平均・最大分岐、強制手割合、誘惑手、最大高さ、難易度スコアの再計算一致

## 6. 保存・マイグレーション単体テスト

- 正常保存の往復
- 非オブジェクト、JSON破損、不正schemaVersion
- 不正配列長、セル値、論理長、負のカウンター
- 未知問題ID、初期盤面ハッシュ不一致
- ルール・生成器・難易度版不一致
- 既知旧版の移行、移行不能データの隔離
- Master Ten以外のlocalStorageキーを削除しない

## 7. UI統合テスト

ゲームセッション統合テストと公開ブラウザ実操作で次を確認する。

- ホームから問題開始、問題一覧、遊び方、設定への遷移
- 2セル選択、合法ペア消去、無効ペアで盤面不変
- Undo、数字追加、ヒント、リスタート確認
- 各操作後の保存と再読込復元
- 勝利画面、次問題、再プレイ、進行状況更新
- 追加ボタンの無効理由、破壊操作の確認
- aria-label、キーボード操作、フォーカス表示用属性

## 8. ビルド・静的検査

- TypeScriptエラーなし、Vitest全成功、Vite本番ビルド成功
- 生成物のURLが `/master-ten-pwa/` を基準にする
- manifest、アイコン、Service Workerを生成物に含む
- ソース・生成物に広告、分析、外部フォント、外部API、内部出典記号がない
- `node_modules`、秘密情報、トークンがGit追跡対象でない

## 9. ブラウザ・公開検査

既存ブラウザ環境を優先し、巨大ブラウザの追加導入は行わない。

- ローカル本番ビルド: console errorなし、全画面、基本ゲーム操作、リロード復元
- レスポンシブ: 320/375/768/1024px相当、縦持ち優先、safe area
- キーボード、画面拡大、reduced motion、高コントラスト、大きく表示
- 公開URL HTTP 200、CSS/JS/manifest/SW/アイコンが404なし
- GitHub Actions成功、問題一覧と問題開始
- オンライン初回後にオフライン再起動、一覧、開始、続き、設定変更

実機iPhone/iPad/Androidや完全なオフライン切替を確認できない場合、推測で成功とせず `manual-test-results.md` に未確認理由と手順を残す。
